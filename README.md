# Taiwan economic research

Pre-registered economic research on Taiwan's open data. Each study is planned and fixed before its outcome data is
opened, attacked by a red team, read by an economist, and only then written up as a working paper.

**Pilot (D280): MRT openings and new businesses.** Did new MRT and light-rail stations change how many businesses
open within 500 m, compared with similar 村里 that got no station? Plan:
https://claude.ai/artifact/7utysuTm74WwbHBXzmL3d9 · literature review: https://claude.ai/artifact/NmRRuKMcabxzAQeCtzk2gP

| Folder | What it holds |
| --- | --- |
| `preregistration/` | The question, outcome, design, tests and kill rules, committed before any outcome data is opened |
| `data/` | Aggregated exports only, each with a `MANIFEST.md` naming its sources and licences |
| `code/` | The analysis, runnable from a clean checkout |
| `paper/` | The working paper |
| `reviews/` | The review editor's rounds (`round-N.md`) |
| `notes/` | Working notes and the spend log |

Author: Nikolas Doan (段皇方). The research is carried out with AI agents, and every paper says so.
